# AGENTS.md

## Layout
Three independent exercises; there is no root build, test runner, CI, or package manifest. Paths below are relative to the repository root.
- `agent/` — C++17 CLI `bibliotheque` (personal library manager), CMake.
- `agent/gui/` — Python UI (customtkinter) driving the C++ core through pybind11.
- `agent/chatsLog/` — manually exported opencode session logs (Markdown). Not generated by the build; commit them with the matching feature when relevant.
- `apprentissage/` — scikit-learn notebooks (Pokémon battle prediction).
- `analyse_image/` — TensorFlow/Keras notebooks (Fashion-MNIST CNN).

Docs, UI strings, comments, and commit messages are in French; keep that convention.

## agent/ (C++)
- Build: `cmake -S agent -B agent/build && cmake --build agent/build`
  (binary: `agent/build/bibliotheque`, Python module: `agent/build/bibliotheque_core*.so`).
- The Python module target needs pybind11; CMake locates it automatically via `python3 -m pybind11 --cmakedir` (pybind11 is preinstalled in this devcontainer). The CLI and the module are built together; the CLI is unchanged.
- `CMakeLists.txt` uses `file(GLOB *.cpp)`: re-run CMake after adding/removing a source file, otherwise the new file is not compiled. `main.cpp` is excluded from the module target.
- Run with a data directory: `cd agent && ./build/bibliotheque -d data`.
  Without `-d`, file paths are empty and loading/saving fails.
- Data lives in `agent/data`. The app writes `books.txt`/`users.txt` in place; menu 13 also creates `*.backup`. Keep the tracked sample data clean (`git status`) and avoid unnecessary saves; do not use temporary copies.
- On-disk format is `|`-separated:
  - books: `title|author|isbn|1|borrowerId` (`1` available, `0` checked out)
  - users: `name|userId|isbn1,isbn2`
- No tests. Verification = warning-free build (`-Wall -Wextra -Wpedantic`) plus a manual CLI run.

## agent/gui/ (Python UI)
- `main.py` is the customtkinter UI (sidebar with the 13 CLI actions, content area, journal, status bar); dependencies in `requirements.txt` (`customtkinter==5.2.2`).
- Actions are enabled step by step; at this stage they are disabled and the UI only loads data (no save).
- C++ `std::cout` messages (loading, saving) are captured for the journal by redirecting file descriptor 1 to a pipe read by a daemon thread; `fflush` is called after each bound call. No temporary files.
- `binding/bindings.cpp` exposes the C++ core (`Book`, `User`, `Library`, `FileManager`) as the `bibliotheque_core` module. It is built with the C++ target above (no separate command); pybind11 is only needed at build time.
- The UI imports the module by adding `agent/build` to `sys.path` (relative to `main.py`).
- The data directory defaults to `agent/data` (option `-d/--data-dir`); tests use that directory — keep `git status` clean.
- The virtualenv `agent/gui/.venv/` is local and not versioned. Create and install (from the repo root):
  - `python3 -m venv agent/gui/.venv`
  - `agent/gui/.venv/bin/pip install -r agent/gui/requirements.txt`
- Run: `agent/gui/.venv/bin/python agent/gui/main.py`. A graphical display is required (`DISPLAY` is forwarded by the devcontainer).
- `tkinter` 8.6 is already installed system-wide; no extra system package needed.

## Notebooks
- Run notebooks with the working directory set to their own folder (`apprentissage/` or `analyse_image/`); every data/model path is relative.
- `apprentissage/`: `datas/dataset.csv` is tab-separated (`delimiter='\t'`). The model is persisted with joblib as `modele/modele_pokemon.mod` (the extension does not indicate the real format).
- `analyse_image/`: the model is a Keras JSON architecture (`modele/modele.json`) plus weights (`modele/modele.weights.h5`), loaded via `model_from_json` + `load_weights`. `test_model.ipynb` expects `images/sandale.jpg`.
- `analyse_image/datas/fashion-mnist_{train,test}.csv` are gitignored and untracked; a fresh clone only has the `.idx*-ubyte` files, so `classification.ipynb` needs those CSVs regenerated or obtained first.
- No requirements file. Install manually: pandas, numpy, matplotlib, seaborn, scikit-learn, joblib, tensorflow/keras, Pillow. The devcontainer preinstalls only pybind11, tk, and venv.

## Git
- Commit messages use French tags, one type per commit: `[FEAT]` (feature), `[FIX]` (bug fix), `[DOCS]` (documentation), `[TACHE]` (build/tooling/config).
- `agent/build/` and `agent/gui/.venv/` are ignored. Large datasets and models under `*/datas/` and `*/modele/` are tracked; do not delete them.
