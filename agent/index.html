Export des données

Exportez les données de la session au format du projet : books.txt et users.txt. Vous pouvez ensuite les placer dans votre dossier agent/data et démarrer bibliotheque -d data. Les exports n'enregistrent pas automatiquement dans le programme C++.

Connexion au moteur C++

Le dépôt utilise actuellement une boucle interactive sur std::cin / std::cout. Pour rendre cette interface persistante et synchronisée avec C++, exposez les opérations de la classe Library dans un serveur HTTP local. Les endpoints proposés sont GET /api/books, GET /api/users, POST /api/books, POST /api/users, POST /api/loans, POST /api/returns et POST /api/save.
